# Fingerprint = path|function|sha1(fn#argindex:expression)[:12]. It is keyed on
# the EXPRESSION, not the line number, so unrelated edits above a site do not
# spuriously trip the lint, and renaming the variable DOES (because that is a
# different site that nobody has reviewed).
#
# CATEGORIES. The lint REJECTS a row with no category, a row whose
# justification is still a TODO placeholder, and a row whose fingerprint
# matches nothing in the tree, so this file cannot silently grow and cannot rot
# into dead hashes:
#   [LEGIT]  individually reviewed. Either the path is confined to the root
#            namespace by construction in a way the tool cannot see, or the
#            site is already below a removable-path guard. Do not "fix" these.
#   [DEBT]   individually reviewed, GENUINELY BLIND on a removable volume,
#            accepted for now. Printed as a loud ledger on every build.
#   [LEGACY] bulk-baselined at #246 and NOT individually reviewed. Treat as a
#            backlog. NEVER add one of these by hand.
#
# A new hit is either ROUTED through hotplug_fs_or_root() or reviewed into
# [LEGIT]/[DEBT] with a real reason. Regenerate only with --update-allowlist,
# which writes TODO notes that the lint then rejects until a human fills them
# in.
